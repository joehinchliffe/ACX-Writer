ACX WRITER - writes a complete self-help book with Claude
=========================================================

It researches the reader, plans the chapters, writes and edits the book,
and writes the descriptions, categories, keywords and a cover brief. One
manuscript works for an Audible (ACX) audiobook and an Amazon KDP eBook
or paperback.


HOW TO USE IT (3 steps)
-----------------------
1. Install the Claude desktop app: https://claude.ai/download
   and sign in. You'll probably need a paid Claude plan (Pro or above)
   to use its Code tab.
   On Windows, also install Git for Windows (https://git-scm.com/download/win)
   and restart the Claude app.

2. Unzip this folder somewhere easy to find, like your Documents folder.

3. In the Claude app, open the Code tab. Under the message box, choose
   "Local", then click the folder button next to it and pick this
   unzipped folder. Then type:

      Help me write a book.

   Claude will ask permission before it runs anything. Click Allow when
   it does.

Claude walks you through the rest, one step at a time: setting things up,
getting your Anthropic API key (you'll need an account with a few dollars
of credit), where to save your books, and your book's title, subtitle and
pen name. Then it writes the book, which takes around 30-60 minutes, checks
it, and tells you where the files are.

Two things to know:
  - Never paste your API key into the chat. Claude will open a file for
    you to paste it into, so it stays on your computer.
  - This needs the Code tab in the Claude desktop app. A normal chat on
    claude.ai can read these files but can't run them.


PREFER NOT TO USE CLAUDE?
-------------------------
Install Python (https://www.python.org/downloads/; on Windows tick
"Add python.exe to PATH"), then double-click "Write a Book (Mac).command"
or "Write a Book (Windows).bat" and answer its questions.
