# Book Description Creation Prompt

## Input Requirements
- Book Title: [Extract from Book Outline]
- Topic: [Extract and elaborate from Book Outline]
- Author Name: [Extract from Book Outline]

## Mandatory Files
- DRP (Dream Reader Persona)
- Book Outline

## Goal
Create an engaging, SEO-friendly, **policy-compliant** description (300–400 words) that speaks directly to the ideal reader’s needs. The description must:

- Avoid **absolute claims** or **guaranteed results** (e.g., “will cure,” “guaranteed success,” “proven results”).  
- Use **supportive and factual language** (e.g., “can help,” “may support,” “practical methods to improve…”).  
- Avoid unverifiable statistics, percentages, or success rates.  
- Avoid misleading performance terms (e.g., “no-fail,” “pass first try,” “science-backed cure,” “40-in-1”).

## Additional Guidelines
- Incorporate SEO keywords naturally.  
- Do not use overpromising or trademarked terms.  
- Use **natural, human-sounding copywriting** and avoid AI clichés.  
- Format with bold for critical points and avoid keyword stuffing.  
- If the book includes health-related content, consider adding a **standard disclaimer** at the end.
- It is imperative that you do not use emojis.
